# Vector assets: SurveyHomeView on iPhone (PWA Solar Survey)

Icons are 24 × 24, stroke 2, round caps, `#16325C`. Recolour them with `.foregroundStyle`. In SwiftUI, use the SF Symbol in the second column. The SVG shows the exact look on the board.

| File | SF Symbol | Used for |
|---|---|---|
| `search.svg` | `magnifyingglass` | header search field |
| `chevron-down.svg` | `chevron.down` | `แก้ไขล่าสุด ▾` sort menu |
| `chevron-right.svg` | `chevron.right` | `ทำต่อ` strip › |
| `calendar.svg` | `calendar` | card footer date · time |
| `photo.svg` | `photo` | card footer photo count |
| `cloud-pending.svg` | `icloud.and.arrow.up` | sync status: waiting (icon only, `#B45309`) |
| `cloud-synced.svg` | `checkmark.icloud` | sync status: synced (icon only, `#3B7420`) |
| `plus.svg` | `plus` | floating add button |
