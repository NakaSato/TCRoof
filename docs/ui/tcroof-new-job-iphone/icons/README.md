# Icons (stroke, `currentColor` unless noted)

Prefer the SF Symbol. Use the SVG only when no symbol matches the board closely enough.

| File | Where | Size / stroke | SF Symbol |
|---|---|---|---|
| `close.svg` | header leading button (cancel), white | 22 pt / 2.4 | `xmark` |
| `chevron-right.svg` | disclosure on picker rows, `#C4C4C7` | 8 × 13 pt / 2.6 | `chevron.right` (13 pt, semibold) |
| `search.svg` | province search field, `#8E8E93` | 18 pt / 2.4 | `magnifyingglass` |
| `clear-circle.svg` | clear button in the province search field (filled, own colours) | 32 pt hit area, 20 pt glyph | `xmark.circle.fill` |
| `check.svg` | selected province row, `#007AFF` | 18 pt / 2.8 | `checkmark` |
| `minus.svg`, `plus.svg` | − / + step buttons on the kW pad, `#1F6FB5` | 22 pt | `minus`, `plus` |
| `delete-left.svg` | backspace key on the number pad | 20 pt | `delete.left` |
| `saved-check.svg` | green circle in the "เพิ่มลูกค้าแล้ว" banner (filled, own colours) | 28 pt | `checkmark.circle.fill` tinted `#70AD47` |

Team dots (10 pt circles in `Team.color`) and the sheet grabber (36 × 5, `#C7C7CC`) are drawn shapes, not icons.
