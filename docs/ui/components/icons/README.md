# Icons: component library (`iPadComponents.dc.html`)

These are vector exports of every icon on the board, at the size and colour they are shown.
- Prefer the SF Symbol in the table and tint it with `Theme`.
- Use the SVG only where no symbol fits (marked **SVG**).

| SVG | Where on the board | SF Symbol |
|---|---|---|
| `chevron-left.svg` | Header back, bottom bar ‹ | `chevron.left` |
| `chevron-right.svg` | Bottom bar ถัดไป › | `chevron.right` |
| `chevron-down.svg` | Dropdown | `chevron.down` |
| `arrow-left.svg` | Primary button `คืนอุปกรณ์` | `arrow.uturn.backward` / `arrow.left` |
| `search.svg` | Search fields | `magnifyingglass` |
| `camera.svg` | Gradient button `กล้อง`, photo slot | `camera` |
| `photo.svg` | Secondary `อัปโหลด` | `photo` |
| `clipboard-add.svg` | Teal button `เพิ่มแบบสำรวจ` | `list.clipboard` |
| `plus.svg` | FAB | `plus` |
| `bell.svg` | Icon button with badge | `bell` |
| `gear.svg` | Icon button | `gearshape` |
| `close.svg` | Icon button ✕, clear field | `xmark` |
| `spinner.svg` | Working state | `ProgressView()` |
| `calendar.svg` | Date field | `calendar` |
| `clock.svg` | Time field | `clock` |
| `location.svg` | `ตำแหน่งปัจจุบัน` | `location` |
| `lock.svg` | Read-only field | `lock` |
| `lock-badge.svg` | Tool row (locked / checked-out) | `lock.fill` |
| `number-pad.svg` | Number field (opens section 9) | `keyboard` / `number` |
| `delete-backward.svg` | Number pad ⌫ | `delete.left` |
| `warning.svg` | Warning banner | `exclamationmark.triangle` |
| `bolt.svg` | Survey card kW | `bolt.fill` |
| `module-tools.svg` | Home menu card illustration | `briefcase.fill` (**SVG** for the large illustration) |
| `compass.svg` | Map compass | **SVG** |
| `play.svg` | Shadow animation play (pause = `pause.fill`) | `play.fill` |
| `fullscreen.svg` | Fullscreen | `arrow.up.left.and.arrow.down.right` |
| `list.svg` | Banner action `ดูคิว` | `list.bullet` |
