# Vector assets: SurveyHomeView (PWA Solar Survey)

Icons are 24×24 with a stroke of 2, round caps and `#16325C`. Recolour them with `.foregroundStyle`. In SwiftUI, prefer the SF Symbol from the second column. The SVG shows the exact look on the board.

| File | SF Symbol | Used for |
|---|---|---|
| `icons/search.svg` | `magnifyingglass` | header search field |
| `icons/lock.svg` | `lock.fill` | locked survey card · ล็อก · อยู่ในงานติดตั้ง |
| `icons/calendar.svg` | `calendar` | card footer date · time |
| `icons/photo.svg` | `photo` | card footer photo count |
| `icons/plus.svg` | `plus` | floating add buttons (stroke 2.6 on the 68 pt button) |
| `icons/close.svg` | `xmark` | close the install picker |
| `icons/chevron-right.svg` | `chevron.right` | next-step strip › |
| `icons/check.svg` | `checkmark` | ✓ ซิงก์แล้ว |

## Marks
| File | What |
|---|---|
| `progress-ring-*.svg` | 58 pt ring: track `#E6ECF3` 4 pt. The arc is `#1F6FB5`, or `#70AD47` at 100 %, with a round cap and starts at 12 o'clock. Centre text: 16 pt bold value + 10 pt `%`. |
| `step-caps-13.svg` | 13-step bar, 6 pt high, gap 3: done `#70AD47`, has missing fields `#B45309`, current `#1F6FB5`, not started `#DDE4ED` |
| `sync-dot-pending.svg` | 8 pt orange dot before `รอซิงก์` (`#F08C00`) |
| `tab-number.svg` | 24 pt step number in the stage tabs: `#1F6FB5` when selected, `#8FA3BC` otherwise |
