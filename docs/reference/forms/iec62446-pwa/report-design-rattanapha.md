## จอในแอป
1. ภาพรวมสถานี — ข้อมูลสถานี, ผู้ทดสอบ+เครื่องมือ (ใหม่), กริดสตริงต่อ inverter (✓ ครบ / ● ตรวจซ้ำ / ○ ว่าง), สภาพการทดสอบ
2. กรอกผลต่อสตริง — สลับ ก่อน / หลัง / IR, ตรวจอัตโนมัติต่อแถว, แผงขวา = ช่องกรอก + 5 ช่องรูป (V/I ก่อน, V/I หลัง, จอ IR)
3. สมรรถนะ — กรอกพลังงานรวม + จำนวนวันจริง → kWh/วัน, Yf, PR, Efficiency; เลือกสาเหตุ PR ต่ำ
4. ตรวจทานและส่งออก — ต้องกรอก / เตือน / แอปแก้ให้ + ไฟล์ตามโฟลเดอร์ส่งมอบ

## สิ่งที่พบในไฟล์รัตนาภา
1. แผ่น INV 2 หัวตารางเขียน "Inverter 1" ซ้ำ (S/N ถูก) → แอปสร้างหัวจาก index
2. "kWp ติดตั้งของ INV" แสดง 123120 (หน่วย W) → แสดง 123.12 kWp
3. พลังงาน "7 วัน" ÷ kWh/วัน = 4.94 / 4.91 วัน → ข้อมูลจริงราว 5 วัน แอปต้องเก็บจำนวนวันและพิมพ์ตามจริง
4. Imp ในคู่ MPPT ต่างกันมาก: INV1 ST2 vs ST1 (5.51 vs 9.44 A, 42%), INV2 ST1 vs ST2 (10.30 vs 13.33 A, 23%) — น่าจะวัดคนละเวลา → เก็บเวลาวัดจาก EXIF ของรูป เตือนเกิน 10% และให้ใส่หมายเหตุ
5. IR ยังเป็น "Normal" ไม่มีตัวเลข MΩ เหมือนชุดเดิม
6. Yf/PR ชุดนี้ตรงสูตร (506.90 ÷ 123.12 = 4.12, ÷ 6.67 = 0.62)
7. ภาคผนวกภาพ (D23F1) 21 หน้า ไม่มีหน้าปก: ก่อน 8 + หลัง 8 + IR 4 + ความเข้มแสง 1 (ตาราง weather station 11/9/2569, ค่า 1045 W/m² กรอบแดง)
