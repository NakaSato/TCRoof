# ลูกค้า กปภ. (PWA) — เอกสารสำหรับ flow ใน TCRoof

แยกจาก `forms/pea-rooftop-2569/` (โซลาร์ภาคประชาชน กฟภ.) เพราะเป็นลูกค้าองค์กร มีหลายโครงการ และแต่ละโครงการใช้เอกสารไม่เหมือนกัน

## โครงสร้างโฟลเดอร์

```
forms/pwa/
├── README.md
├── catalog/                         คลังชนิดเอกสารกลางของลูกค้า (38 ชนิด)
│   ├── index.json                   ดัชนี id → ชื่อ/กลุ่ม/ไฟล์ + นิยาม scope, producer, origin
│   ├── internal.json                ภายใน · 18 — ทีมเราทำและจบในทีม
│   ├── internal-signoff.json        ภายใน → ภายนอก · 7 — เราร่าง กปภ. ลงนาม/ออกเลข/อนุมัติ
│   ├── external.json                ภายนอก · 13 — ขอจาก กปภ. ส่วนกลาง/สาขา, เทศบาล, กกพ., ผู้ผลิต
│   └── erc-pk2-checklist.json       Check list พค.2 ของ กกพ. 23 ข้อ ผูกกับ id เอกสาร
└── projects/
    └── solar-rooftop-energy-mgmt/   โครงการจัดการพลังงานไฟฟ้า Solar Rooftop กปภ.
        ├── project.json             ขั้นตอน MP 1.1–3.2, โฟลเดอร์ส่งมอบ, ชื่อไฟล์, กฎเงื่อนไข
        └── flow.mmd                 flowchart (Mermaid) สีตามภายใน/ลงนาม/ภายนอก
```

ฟอร์ม IEC 62446 ของ กปภ. อยู่ที่ `forms/iec62446-pwa/` (ยังไม่ได้ย้าย) อ้างจาก `iec62446_report` ใน `catalog/internal.json`

## เพิ่มโครงการใหม่

1. สร้าง `projects/<ชื่อโครงการ>/project.json` โดยคัดลอกจากโครงการเดิม
2. อ้างเอกสารด้วย `id` จาก `catalog/index.json` — ถ้ามีเอกสารชนิดใหม่ เพิ่มลงไฟล์ catalog ตามกลุ่ม แล้วอัปเดต `index.json`
3. ใส่ `site_params` และ `rules` ที่ต่างจากเดิม แล้วทำ `flow.mmd` ของโครงการ

## หลักที่ใช้

- **origin** (ไฟล์ catalog): ใครเป็นต้นทาง — กำหนดว่าแอป *สร้าง* / *ร่างแล้วติดตามลายเซ็น* / *ติดตามการขอ*
- **scope**: ใช้ซ้ำระดับไหน — `org` → `contractor` → `project` → `branch` → `site`
- **ไฟล์เดียวใช้หลายที่**: บิลค่าไฟ, แผนที่, SLD, รายงานภาพติดตั้ง ซ้ำกันระหว่างชุดขนานไฟกับ พค.2
- **เงื่อนไขต่อสถานี**: inverter ≥ 200 kVA → พค.2; เทศบาลกำหนด ขออนุญาต (ข.1) หรือ แจ้งยกเว้น; ภาค → คู่มือ O&M
- **สถานะเอกสาร**: `missing → requested → draft → signed → submitted → approved` + `expires_at` สำหรับ กว./ตพค.
- **ข้อมูลส่วนบุคคล**: บัตรผู้มอบ/ผู้รับมอบต้องปิดศาสนา กรุ๊ปเลือด วันเกิด; แบบตรวจสอบส่วนที่ 1 มีเลขบัตรวิศวกร — อย่าเก็บเป็นข้อความในแอป
