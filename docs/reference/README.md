# เอกสารอ้างอิงหลัก (master reference)

ข้อมูลต้นทางที่แอป TCRoof ใช้ออกแบบขั้นตอนงาน เอกสาร และใบอนุญาต รวมไว้ที่เดียว ไฟล์ใน `forms/` คัดลอกจาก Project
"TCRoof" บน claude.ai (13 ต.ค. 2569) ถ้าแก้ ให้แก้ทั้งสองที่ หรือถือฉบับใน repo เป็นหลักแล้วอัปเดต Project ตาม

แผนภาพทั้งหมดอยู่ใน canvas "ขั้นตอนงานบ้าน Solar Rooftop": https://claude.ai/artifact/1QHYLS1kovMUkLWdfW222y

## ขั้นตอนตามชนิดงาน

| ชนิดงาน | ขั้นตอน กกพ. | ใบอนุญาตหลัก | แผ่นใน canvas |
|---|---|---|---|
| งานบ้าน PEA ผลิตใช้เอง | การไฟฟ้า ต่ำกว่า 200 kVA: ทีมไม่ต้องแจ้ง กกพ. เอง PEA ส่งข้อมูลให้หลังตรวจผ่าน | PPIM คำขอเชื่อมต่อ · PEA พิจารณาแบบ ≤ 15 วันทำการ · ตรวจระบบ ≤ 30 วันทำการ | ผลิตใช้เอง · ลำดับ ผลิตใช้เอง |
| งานบ้าน ขายไฟส่วนเกิน 2569 | เหมือนข้างบน ระยะเวลาตามประกาศโครงการ (รอยืนยันกับ PEA) | PPIM ขอขายไฟ → ประกาศรายชื่อ → สัญญา → ขออนุญาตเชื่อมต่อ | ขายไฟส่วนเกิน · ลำดับ ขายไฟส่วนเกิน |
| สถานี กปภ. ต่ำกว่า 200 kVA | การไฟฟ้า ต่ำกว่า 200 kVA | ขอขนานไฟ PPIM · อ.1 / แจ้งเทศบาล | ลำดับ แอป โครงการ PWA |
| สถานี กปภ. 200 kVA ขึ้นไป | การไฟฟ้า 200–1,000 kVA: ยื่น พค.2 (พพ. ให้ความเห็น ≤ 30 วัน) | ขอขนานไฟ PPIM · พค.2 · อ.1 / แจ้งเทศบาล | กกพ. การไฟฟ้า 200–1,000 kVA · ลำดับ แอป โครงการ PWA |
| โรงงาน / อาคาร ในโครงข่ายเอกชน | เอกชน ต่ำกว่า 200 kVA หรือ 200–1,000 kVA: ทีมยื่นแจ้งยกเว้นเอง | ขอความเห็นแบบจากเจ้าของโครงข่าย · พค.2 ถ้า 200 kVA ขึ้นไป | กกพ. เอกชน … · ลำดับ แอป เอกชน … |

ขนาดวัดจาก kVA ของอินเวอร์เตอร์รวมตาม datasheet ไม่ใช่ kWp ของแผง ตั้งแต่ 1,000 kVA ต้องขอใบอนุญาตผลิตไฟฟ้า ไม่อยู่ในชุดนี้

## แผนงาน MP (Project Plan)

| Part | หัวข้อ |
|---|---|
| PERMIT | 1.1 Kick Off · 1.2 Engineering Approve · 1.3 ส่งมอบพื้นที่และเข้าดำเนินการติดตั้ง · 1.4 ยื่นขออนุญาตดัดแปลงอาคาร (อ.1) · 1.5 ยื่นขอใบอนุญาต พค.2 · 1.6 ยื่นขอขนานไฟ |
| ติดตั้งอุปกรณ์ | 2.1 โครงสร้างรองรับแผง + Walkway · 2.2 อุปกรณ์ไฟฟ้าด้าน DC · 2.3 แผง · 2.4 Firefighter Safety Switch · 2.5 อินเวอร์เตอร์ · 2.6 อุปกรณ์ไฟฟ้าด้าน AC · 2.7 ตู้ควบคุม · 2.8 ระบบสื่อสาร + Zero Export · 2.9 Solar Monitoring |
| การขออนุญาตและการทดสอบ | 3.1 Pre-Commissioning Test · 3.2 อบรมการใช้งานและการบำรุงรักษา |

ในแอป (`TCRoofCore/MasterSchedule.swift`) มีหัวข้อ COP น้ำหนัก 0 เป็น 1.6 และยื่นขอขนานไฟเป็น 1.7 ตามไฟล์ Excel ของบริษัท
