## ขั้นตอน

### 1. โมเดล (SurveyCore)
- เพิ่ม `public enum JobStage: String, Codable, CaseIterable { case survey, install, maintenance }`
- เพิ่มใน `Job`:
  - `public var stage: JobStage = .survey`
  - `public var install: InstallInfo?`
- `InstallInfo`:
  - `doneSteps: Int`, `currentFraction: Double` (0–1 ของขั้นที่ทำอยู่)
  - `team: String`, `dueDate: Date?`, `movedAt: Date`
- ขั้นติดตั้ง 7 ขั้น เก็บเป็น static list:
  `ส่งวัสดุเข้าหน้างาน`, `ติดตั้งโครงสร้างราง`, `ติดตั้งแผงโซลาร์`, `เดินสาย DC · ตู้ DC`, `ติดตั้งอินเวอร์เตอร์ · ตู้ AC`, `ทดสอบระบบ`, `ขนานไฟ · ส่งมอบ`
- **สำคัญ:** ไฟล์ JSON งานเดิมต้องเปิดได้ ต้องเขียน `init(from:)` ที่ใช้ `decodeIfPresent` แล้ว default เป็น `.survey` / `nil`
  - เพิ่ม test ถอดรหัส JSON เก่าที่ไม่มี field ใหม่
  - ตรวจว่า `WebBackup` และ Drive sync ยังทำงาน

### 3. SurveyHomeView
- **แถบแท็บ** ใต้หัวสีน้ำเงิน:
  - `① งานสำรวจ n งาน · ② งานติดตั้ง n งาน · ③ งานบำรุงรักษา n งาน`
  - segmented แบบในภาพ: แท็บที่เลือกพื้นขาวมีเงา มุมโค้ง 10 สูง ≥ 44 pt
  - เก็บแท็บล่าสุดด้วย `@AppStorage`
  - นับ "งานสำรวจ" = ทุกงาน รวมงานที่ย้ายไปติดตั้งแล้ว (ตรงกับแบบ 7 งาน) เพราะงานที่ย้ายแล้วยังแสดงเป็นการ์ดล็อก
- **แท็บงานสำรวจ:**
  - กล่องตัวเลข 4 ช่อง + รายการเดิมทั้งหมด (filter/sort/search เดิม)
  - ปุ่ม `+ งานสำรวจใหม่` ย้ายจากหัวไปเป็นปุ่มลอยกลม 68 pt มุมขวาล่าง เปิด `NewJobSheet` เหมือนเดิม
- **แท็บงานติดตั้ง:**
  - รายการงาน `stage == .install` ใช้ grid เดียวกัน
  - ปุ่มลอย `+ เพิ่มโครงการ` (แคปซูล) เปิด sheet ตามข้อ 5
  - ถ้าว่าง แสดงกล่องเส้นประ "ยังไม่มีงานติดตั้งในเครื่องนี้" + "กด "เพิ่มโครงการ" เพื่อดึงงานสำรวจที่ครบ 100% มาเป็นงานติดตั้ง"
- **แท็บงานบำรุงรักษา:** กล่องว่างแบบเดียวกัน ข้อความ "ยังไม่มีงานบำรุงรักษา" (ยังไม่ต้องมีปุ่มเพิ่ม)
- กล่องตัวเลข 4 ช่องแสดงเฉพาะแท็บงานสำรวจ

### 4. JobCard
- **งานสำรวจที่ `stage == .install` (การ์ดล็อก ในแท็บงานสำรวจ):**
  - พื้น `#F5F7FA` และป้ายรูปกุญแจ "ล็อก · อยู่ในงานติดตั้ง" (พื้น `#DDE4ED`) ข้างป้ายสถานะ
  - ปุ่มล่างเป็น `งดแก้ไข · ดูได้อย่างเดียว · ดูรายงานสำรวจ ›`
  - แตะแล้วเปิดรายงาน/editor แบบอ่านอย่างเดียว ถ้ายังไม่มีโหมดนี้ ให้เพิ่ม `readOnly` ใน `JobEditorView` ปิดการแก้ไขทุก field
  - เมนูกดค้างเหลือแค่ "ส่งออกข้อมูลงาน"
- **การ์ดงานติดตั้ง (แท็บงานติดตั้ง):**
  - ป้าย `กำลังติดตั้ง` (น้ำเงินอ่อน)
  - วงแหวน % = `(doneSteps + currentFraction) / 7`
  - แถบขั้น 7 ช่อง แทน 13 ช่อง: มิ้นต์ = ครบ, น้ำเงิน = ทำอยู่, เทา = ยัง
  - ปุ่ม `ขั้น 4/7 · เดินสาย DC · ตู้ DC ›`
  - ป้าย `ทีม TCR02` และ `ส่งมอบ 6/10/2569` (ถ้าไม่มีค่า: `ยังไม่กำหนดทีม` / `ยังไม่กำหนด`)
  - แถวล่างเหมือนการ์ดเดิม (วันที่ · จำนวนภาพ · สถานะซิงก์)
  - แตะแล้วไปหน้า "ติดตามงานติดตั้ง": ยังไม่อยู่ใน task นี้ ให้ทำ `InstallTrackingView` เปล่าไว้ก่อน มีหัวข้อชื่องาน + ข้อความ "อยู่ระหว่างพัฒนา" แล้วใส่ TODO อ้าง canvas บอร์ด `iPadInstall.dc.html`

### 5. Sheet "เพิ่มโครงการติดตั้ง"
- หัว: "เพิ่มโครงการติดตั้ง" + รอง "ดึงข้อมูลจากงานสำรวจ · เลือกได้เฉพาะงานที่สำรวจครบ 100%" + ปุ่มปิด ✕ (44 pt)
- รายการงาน `stage == .survey` ทุกงาน เรียงให้งานครบ 100% ขึ้นก่อน แต่ละแถว:
  - `NO.xxx`
  - ชื่อโครงการ
  - `สถานที่ · kWp · n รูป`
- ปุ่มขวาของแถว:
  - งาน 100%: `เพิ่มได้` (น้ำเงินทึบ) กดแล้วเรียก `moveToInstall`, ปิด sheet และสลับไปแท็บงานติดตั้ง
  - งานไม่ครบ: `เพิ่มไม่ได้` (เทา disabled) และแถวสีจาง
  - **ไม่แสดงแถบ %** ในแถว
