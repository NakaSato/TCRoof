# เอกสารสถานี กปภ. (PWA) — คลังเอกสาร 44 ชนิด

ข้อมูลอ้างอิงสำหรับ TCRoof: เอกสารของงานสถานี กปภ. มีอะไรบ้าง ใครทำ ใครลงนาม ใช้ในชุดยื่นไหน และแอปนับความคืบหน้าอย่างไร
หน้าจอ `เอกสารสถานี กปภ.` (`StationDocsScreen`) แสดงจากคลังนี้โดยตรง

**ต้นทางของข้อมูลคือโค้ด** `TCRoofKit/Sources/TCRoofCore/StationDocs.swift` (`StationDocs.kinds`, `StationDocs.pk2Checklist`)
ถ้าเพิ่มหรือแก้ชนิดเอกสาร ให้แก้ที่โค้ดก่อน แล้วแก้ตารางในไฟล์นี้ให้ตรงกัน `id` ที่มีอยู่แล้วห้ามเปลี่ยน เพราะสถานะของแต่ละสถานีเก็บตาม `id`

คลังมาจาก 2 แหล่ง: catalog ของโครงการ (`forms/pwa/catalog/`, 38 ชนิด) และไฟล์ติดตามสถานะ PPA เฟส 3–4 (6 ชนิด มีเครื่องหมาย ★ ในตาราง)

## 1. คำที่ใช้ในตาราง

| ชุดยื่น | จำนวน | หมายเหตุ |
|---|---|---|
| ขนานไฟ | 18 | |
| พค.2 | 26 | มีเฉพาะสถานี 200 kVA ขึ้นไป · 6 ชนิดมีเงื่อนไข `over200kVA` |
| อาคาร | 11 | ข.1 และ อ.1 ใช้เมื่อขออนุญาต หนังสือแจ้งยกเว้นใช้เมื่อแจ้ง ถ้ายังไม่รู้ แสดงทั้งสามใบ |
| ทดสอบ | 3 | |
| ส่งมอบ | 10 | |

## 6. สถานะและความคืบหน้า

| สถานะ (`Status`) | ในแอป | พร้อมยื่น |
|---|---|---|
| `missing` | ยังไม่มี | |
| `requested` | ขอแล้ว รอรับ | |
| `draft` | ร่างแล้ว | |
| `signed` | ลงนามแล้ว | ✓ |
| `submitted` | ยื่นแล้ว | ✓ |
| `approved` | อนุมัติแล้ว | ✓ |
| `notNeeded` | ไม่ใช้กับสถานีนี้ | ไม่นับ |

- เอกสาร "ทีมเราทำ" ไม่มีสถานะ `requested` และเอกสาร "ขอจากภายนอก" ไม่มีสถานะ `draft`
- ความคืบหน้าของชุดยื่น = จำนวนที่พร้อมยื่น ÷ จำนวนเอกสารของชุดนั้นที่สถานีต้องใช้ เอกสารที่ตั้งเป็น `notNeeded` ไม่นับทั้งตัวตั้งและตัวหาร
- สถานีที่ไม่ต้องดับไฟ: ตั้ง `outage_letter` และ `outage_attachment` เป็น `notNeeded`
- 200 kVA: ถ้าไม่ได้ตั้งเอง (`Station.over200kVA` เป็น nil) แอปใช้ขนาดอินเวอร์เตอร์รวมของงาน ≥ 200
- เอกสารที่มีวันหมดอายุ (`engineer_license`, `pwa_poa_order`) เตือนเมื่อหมดอายุแล้วหรือเหลือไม่เกิน 30 วัน
- สถานะของเอกสารต่อสถานีเก็บใน `Station.docs` ของงาน ส่วนเอกสารที่ใช้ร่วมเก็บใน `Library.docs` ในเครื่อง ทั้งสองเป็น `id → DocState`

## 7. เอกสารที่แอปร่างให้

เอกสารที่ `StationDocs.draft(for:)` ตอบ จะมีปุ่ม `ร่างในแอป` ในหน้าเอกสาร แอปเขียน PDF จากข้อมูลสถานีและคำตอบที่กรอก เก็บเป็นไฟล์ของเอกสารนั้นในแฟ้มงาน แล้วตั้งสถานะเป็น `draft` ลงนามบนกระดาษ

| `id` | สิ่งที่กรอก | เก็บที่ | ข้อความ |
|---|---|---|---|
| `outage_letter` | เลขที่ · ลงวันที่ · เรียน · วันและเวลาดับไฟ · ผู้ลงนามและตำแหน่ง | `Station.outageLetter` | ข้อความมาตรฐานใน `OutageLetter.standardBody` ทีมแก้ได้ในแอป (`body`) |

ข้อมูลสถานีในจดหมายมาจากงาน: ชื่อสถานี (`projectName`) ที่อยู่และจังหวัด ขนาด kWp และชื่อผู้รับจ้างจากตั้งค่ารายงานประจำ หัวจดหมายใช้ข้อมูลบริษัทในคลังเอกสารบริษัท ถ้ายังไม่ได้กรอก ใช้ชื่อผู้รับจ้างอย่างเดียว

## 9. ยังต้องยืนยัน

1. **`outage_attachment` ขอจากใคร** ไฟล์ติดตามสถานะไม่ได้ระบุ ในโค้ดยังไม่มี `obtainFrom` และหมายเหตุเขียนว่า "ขอตามที่การไฟฟ้ากำหนด"
2. **ข้อความของหนังสือแจ้งดับไฟ** เขียนขึ้นเองตามรูปหนังสือทั่วไป ต้องเทียบกับฉบับที่บริษัทใช้จริง รวมถึงผู้รับหนังสือ (การไฟฟ้า หรือ กปภ.สาขา)
3. **เลขที่ TC-PML-…** แอปให้กรอกเอง ยังไม่ได้รันเลขให้ เพราะยังไม่รู้ว่าเลขรันต่อปี ต่อโครงการ หรือต่อสถานี
