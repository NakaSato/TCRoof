## 1. Excel — `1_Form_ IEC 62446 Test Report_PWA.xlsx`

**หัวเรื่อง:** โครงการจัดการพลังงานไฟฟ้าจากระบบผลิตไฟฟ้าพลังงานแสงอาทิตย์ที่ติดตั้งบนหลังคา (Solar Rooftop) การประปาส่วนภูมิภาค —
ตารางตรวจสอบระบบก่อนและหลังการเชื่อมต่อฯ ตามมาตรฐาน IEC 62446 และภาพถ่ายความร้อน
โลโก้ กปภ. + กฟภ. อยู่มุมขวาบน • A4 แนวนอน • พื้นที่พิมพ์ A1:AB35

**โครงแผ่นงาน:** inverter ละ 2 แผ่น → `INV 01-ก่อน`, `INV 01-หลัง`, `INV 02-ก่อน`, `INV 02-หลัง`
แผ่น INV 01 เป็นข้อมูลหลัก แผ่นอื่นลิงก์สูตรหัวเรื่องและสภาพการทดสอบมาจาก INV 01

**คอลัมน์:** inverter ละ 10 MPPT × 2 ช่อง = 20 ช่องสตริง (คอลัมน์ E..X) ส่วน Y/Z = ผ่าน/ไม่ผ่าน และ AA = หมายเหตุ (ก่อน/หลังการเชื่อมต่อ)

### รูปแบบค่าในเซลล์
- `Normal` = ผลปกติ (ใช้กับช่องที่ merge ทั้งแถว) → เก็บเป็น `"normal"`
- `P` ในฟอนต์ Wingdings = ✓ → เก็บเป็น `"pass"`
- `1000V` เป็นข้อความ → เก็บเป็นตัวเลข `1000`
- อุณหภูมิ/แสงเป็นข้อความพร้อมหน่วย (`34.3 (ºC)`) → เก็บเป็นตัวเลข แล้วใส่หน่วยตอน export
- System Efficiency เป็นสัดส่วน (0.15) แสดงผลเป็น %

## 4. สิ่งที่พบในฟอร์มเดิม (ควรแก้ในแอป)

1. **Yf ของ INV1 ไม่ตรงกับสูตร:** 457.18 ÷ 145.92 = **3.13** แต่ฟอร์มกรอก 2.93 ส่วน PR 0.69 คำนวณจาก 2.93 (ถ้าใช้ 3.13 จะได้ PR ≈ 0.74) ของ INV2 ใกล้เคียงกัน (3.37 กับ 3.33) → แอปควร**คำนวณ Yf และ PR ให้เอง**
2. **ค่าหลังเชื่อมต่อ (แถว 17, 19) ว่างทุกแผ่น** ทั้งที่ Word มีรูปวัดหลังเชื่อมต่อครบทุกสตริง → ควรกรอก Vmp / Imp
3. **คอลัมน์ ผ่าน/ไม่ผ่าน ว่างทั้งหมด** → แอปคำนวณจากเกณฑ์ในตารางข้อ 1 แล้วติ๊กให้
4. **IR ไม่มีตัวเลข** มีแค่ "Normal" → เก็บค่า MΩ จริงต่อสตริง (รูปหน้าจอเครื่องวัดมีค่าอยู่แล้ว)
5. **ไม่มีวันที่ทดสอบ ผู้ทดสอบ และ serial เครื่องมือ** (ในรูปเห็นแคลมป์มิเตอร์ เครื่องวัด IR และ weather station) → เพิ่มในแอป
6. แผ่น "หลัง" คัดลอกค่า Voc และสภาพอากาศมาจากแผ่น "ก่อน" → ถ้าวัดคนละวัน ควรแยกเก็บ `conditions.before` / `conditions.after`
7. System Efficiency ต้องใช้พื้นที่แผงจาก datasheet (`module.areaM2`) ในฟอร์มเดิมยังไม่ได้บันทึก

## 5. สูตรที่แอปใช้
```
installedKWp      = Σ moduleCount × powerW / 1000
Yf (kWh/kWp/วัน)  = dailyEnergyKWh / installedKWp
Yr (h/วัน)        = avgIrradiationKWhM2Day / 1 kW/m²
PR                = Yf / Yr
dailyEnergyKWh    = sevenDayEnergyKWh / 7
System Efficiency = dailyEnergyKWh / (avgIrradiationKWhM2Day × moduleCount_total × areaM2)
Voc check         = |V − median(V ของสตริงที่แผงเท่ากัน)| / median ≤ 5%
IR pass           = min(+E, −E) ≥ 1 MΩ @ 1000 V
```
